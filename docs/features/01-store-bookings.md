As a B&B owner   
I want to be able to store bookings for a single room   
So I can track bookings for the room

**Features include:**
* Create bookings that contain:
  * First name
  * Last name
  * Price of booking
  * Deposit paid
  * Checkin date
  * Checkout date
* Edit bookings
* Delete bookings
* Show bookings in list form
